# 📰 News Monkey – Daily News Application

## 📌 Description
News Monkey is a responsive news web application built using **React.js** that displays real-time daily news from various categories such as Business, Entertainment, General, Health, Science, Sports, and Technology.

The application fetches live news data from an external News API and presents it in a clean, card-based layout, allowing users to easily browse and read the latest headlines.

---

## ✨ Features
- 🗂 Category-wise news filtering
- 🔍 Browse daily news across multiple domains
- 🌐 Real-time news fetching using API
- 📱 Fully responsive design for all screen sizes
- ⏳ Loading indicators for better user experience
- 📰 Clean and modern UI with news cards
- 🔄 Pagination for smooth navigation between articles

---

## 🛠 Tech Stack
**Frontend:** React.js, JavaScript, HTML, CSS  
**API:** News API  
**Tools:** Git, GitHub, VS Code
